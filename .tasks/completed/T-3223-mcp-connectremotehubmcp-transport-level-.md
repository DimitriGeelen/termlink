## RCA

**Symptom:** an MCP caller whose `hub.auth` call failed at the transport level got "Authentication error: …" with no next step.
**Root cause:** T-2625 added `auth_failure_hint` to both CLI failure paths; the MCP twin got the credential-path text (T-2268) but not the transport path.
**Why structurally allowed:** duplicated twins with no link between them (C-26).
**Prevention:** `auth_failure_hint_mcp` mirrors the CLI text and is pinned by a unit test; twin drift is now listable with `check-mcp-cli-twin-drift.sh`.
