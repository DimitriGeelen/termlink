# T-2543: README Durability guarantee overstated — omits T-2427 periodic sweeper cadence pruning (reliability doc-accuracy)

## Context

Reliability lens (Constitutional Directive #2, "no silent failures / observable
execution") on the campaign's purpose review found an OVERSTATED durability
guarantee. README.md:52 states absolutely: "nothing is pruned until an explicit
`channel sweep`". This was true pre-T-2427 but is now stale: the T-2427 opt-in
periodic retention sweeper (`TERMLINK_SWEEP_INTERVAL_SECS`) prunes bounded topics
(`days`/`messages`/`latest`/`latest-per-cv-key` — all except `Forever`) on a
background cadence with NO explicit `channel sweep` RPC
(`crates/termlink-hub/src/retention_sweeper.rs:107-152`, spawned at
`server.rs:337-344`). The CLAUDE.md topic-growth-canary guidance actively nudges
operators to enable this sweeper to bound high-rate topics, so the overstatement
matters in practice. Code is correct + observable (`retention_sweep_pruned_total`
counter, `router.rs:996`); only the doc overstates persistence. Fix = one-line
README correction (no code change). CHARTER.md / ARCHITECTURE.md do NOT carry the
claim (grep-verified — single copy).
