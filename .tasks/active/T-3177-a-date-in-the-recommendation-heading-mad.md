## RCA

**Symptom:** the Watchtower decide form on T-2879 returned `ERROR: ## Recommendation section
required before decision`, on a task whose recommendation had been written on 2026-09-25 and was
plainly present in the file.

**Root cause:** `lib/task-audit.sh:159` requires a literal `**Recommendation:**`:

    ^[[:space:]]*[-*]?[[:space:]]*\*\*Recommendation:\*\*[[:space:]]*\*{0,2}[A-Za-z]

The line on disk read `**Recommendation (2026-09-25, after measurement):**`. The parenthetical
sits between the word and the colon, so the marker never matched and the section extractor
returned content the substantive check then rejected. The section was not missing — it was
invisible. A date in a heading made a NO-GO undecidable.

**Why structurally allowed — and this is the more useful half.** The error message names THREE
required fields (`**Recommendation:**`, `**Rationale:**`, `**Evidence:**`) and the implementation
checks exactly ONE. So the diagnostic points at two innocent fields: a reader can dutifully add
the `**Evidence:**` block it demands, fail again for the unchanged real reason, and have no way to
learn which field was at fault. The message describes an intended contract; the code enforces a
narrower one. That gap is what turned a one-character problem into an undecidable task.

**Prevention.** Fixed the marker (content untouched) and verified with the framework's own
`audit_inception_recommendation`, not a copy of its regex — five times this session a
re-implemented predicate produced a plausible wrong answer (PL-386), so the check was run against
the real function. Also pre-verified the two gates that fire earlier (T-973 review marker,
`audit_task_placeholders`) so the retry cannot hit a second wall. The message/implementation
mismatch is in vendored code (G-062) and is upstream's to close; recorded here rather than patched.

**Process note.** The inception commit-budget gate blocked the commit of the fix that unblocks the
decision the gate was demanding, while Tier 0 correctly refused to let an agent record that
decision. Neither was bypassed: the fix went to disk (where the validator reads it, so the
operator's retry works immediately) and the commit was attributed to this task instead. Fourth
instance today of a gate blocking its own prescribed remedy.
