**2. Options**

- **A.** Strongest: matches observed truth, one line, lapses at W2, keeps (b). Weakness: blind to a genuine push-wake straggler whose heartbeat loses `pty_session` (only (b) with a state file catches that); "laps at W2" is unenforced — no W2 date is given; and it arguably amends PD-234, requiring the rule-1-style documented approval the bundle never confirms is obtainable.

Weakness: a manual treadmill — 13 identical reasons now, a false page plus a git commit for every new project until W2; it converts an operator decision into ongoing toil and trains people to close red tasks reflexively.

Weakness: the meaningful part (the W2 doorbell) doesn't exist, so it either can't be built or would alarm on the known gap; it duplicates the notify-sidecar canary and the prover; and it burns the one-in/one-out cap on overlap while gating a config fix needed today.

**3.
